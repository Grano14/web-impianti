# Immagini del sito

Metti qui le foto reali del sito (es. `hero.jpg`, `fotovoltaico-tetto.jpg`).

Poi apri `src/config/images.ts` e scrivi il nome del file nel campo `src`
dell'immagine corrispondente. Finché `src` è vuoto, il sito mostra un
riquadro grigio segnaposto.

Consigli:
- formato `.jpg` o `.webp`, larghezza circa 1600 px, peso sotto i 300 KB
- proporzioni 4:3 (il riquadro ritaglia automaticamente le foto più larghe o più alte)
- usa solo foto di cui hai i diritti e, se ritraggono persone, il loro consenso
